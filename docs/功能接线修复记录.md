## 八、标记为什么会丢（2026-11-15 晚）

现象：改完代码重建、重新打开软件后，之前点的心数和分级就没了。

根因：`src/main/db/open.cjs` 用的是 WAL + `synchronous = NORMAL`，这种组合下提交不保证立刻刷盘，只有检查点才落盘。以前每次重建都是强制结束进程（Stop-Process -Force），最后一次检查点之后的写入全部丢掉，所以整场会话里点的标记都会消失。

修法（三处）：

1. `open.cjs` 改成 `synchronous = FULL`，每次提交都落盘，强杀也不丢；库只有几 MB，这点开销可忽略。
2. `main.cjs` 的 `will-quit` 里先 `wal_checkpoint(TRUNCATE)` 把 WAL 收进主库再 `closeDb()`。
3. 同时留一份 `%APPDATA%\aiyview\index.sqlite.bak`（正常退出时覆盖），万一库文件损坏可以拿它顶上。

另外：`ImageArea` 的图区在鼠标进入时会把搜索框的焦点收走，否则焦点还在输入框里，`1`~`5`、`x`、`Alt+数字` 这些快捷键会被当成打字吞掉——这也是「悬停只能打心、快捷键标废没反应」的真实原因。

以后的验证流程也改了：改完代码用 `window.close()` 正常退出等进程结束，不再用强杀。

## 十二、「添加文件夹」点了没反应（2026-11-15 深夜）

**根因**：`library:pick` 里给目录对话框传了 `properties: ['openDirectory', 'multiSelections']`。Windows 的目录选择对话框不支持多选文件夹，Electron 传这两个组合时系统只返回「取消」、对话框根本不显形（实测耗时约 130ms 就 resolve `canceled:true`），而 `addFolder` 对「取消」是静默 return，用户看到的就是「按钮没反应、加不了新文件夹」。

**修法**：

1. `src/main/services/libraryPicker.cjs`：`properties` 只留 `['openDirectory']`，并留注释防止有人再加回 `multiSelections`；对话框改为不挂父窗口调用（挂父窗口且窗口不在系统前台时同样会被秒取消）；每次调用把 `canceled / paths / cost` 写进 `ipc` 日志，以后再出问题能直接从日志判定。
2. `src/main/services/tags.cjs` 的「导入标签 CSV」也去掉挂父窗口，避免同一种前台依赖。
3. 左栏三个分组标题从「`<button>` 里嵌 `<span>` 当按钮」改成「`div.side-head` + `button.side-head-toggle`（折叠）+ `button.icon-btn`（＋ / 打标）」并列结构，两个点击目标互不干扰，也避免嵌套可交互元素的隐患。

**验证**：打包版 `release/v3.0/win-unpacked` 起 CDP 实例，真实点击「文件夹」右侧 ＋，枚举窗口能看到 `PulseFolderPickerWindow | 添加文件夹`；按 ESC 取消后日志出现 `library:pick 结束 {"canceled":true,"cost":11537}`，说明对话框正常挂起等用户选择。

## 十三、搜索扩三路 / 缩略图索引 / 查看器原图 / 图标条分隔（2026-11-15 深夜）

1. **搜索不再只搜文件名**：`imageRepository.buildFilters` 的 `nameLike` 现在一次查三处——`images.file_name`、`tags.name`/`name_zh`（经 `image_tags`）、`image_prompts.positive`/`negative`；输入以 `tag:` 开头时只在标签里找。搜索框提示改成「搜文件名 / 标签 / 提示词…」。
   * 实测：`二次元` 命中文件名；`tag:monochrome` 命中打过该标签的图；提示词那一路在库副本上插一条 `special magic word` 后搜 `magic` 命中对应图（真库 59 条 `image_prompts` 同样生效）。
2. **缩略图慢加载的真根因**：磁盘上已有 1318 张缓存缩略图，但 `thumbnails/index.json` 只有 45 条——`ThumbnailCacheStore.put()` 只把条目放内存、从不落盘保存（只有启动时 `init()` 存过一次），所以每次开软件几乎全部重新生成，`thumb:get` 批量 20 张稳定 300~600ms。
   * 修法：`put()` 后 1.5s 防抖写索引；退出时 `will-quit` 调 `flushThumbCache()` 强制落盘；`init()` 增加 `reindexDisk()`，把目录里「索引没记」的 jpg（文件名 `<md5>_<尺寸>.jpg`）补登记，源路径/mtime 未知的条目在首次命中时补上 `mtime`，之后照常判失效。
   * 实测：启动后索引 1318 条 = 磁盘 1318 个文件；打包版里一次取 12 张缩略图 cold 1ms / warm 0ms（原来是 300~600ms 冷算）。
3. **大图查看器**：按住空格临时按 1:1 原始像素看（松开回到原样，平移位置也还原）；`0` 键或双击画面在「适应窗口 ↔ 1:1」之间切换。样式加 `.viewer-stage img.actual { max-width/max-height: none }`。
   * 实测：适应窗口时图 420×752，按住空格变 768×1376（= 原图 naturalWidth/Height），松开回 420；按 `0` 切到 1:1 宽 768。
4. **双击被屏蔽的缩略图**：第一次双击只当「显示」用（不进大图），露出后再双击才打开查看器；用 `gestureRef` 按手势判定，不会让「已显示」的图反而点不开，也避免双击过程中「显示又复原」闪一下。
   * 实测：第一次双击 `opened=false / revealed=true`，第二次双击 `opened=true`。
5. **左栏收起成图标条**：按「浏览 / 筛选 / 管理」三段加小分隔线（`.rail-sep` 上下 6px）。
   * 实测：收起后按钮 top = 36 / 83 / 115 / 147 / 194 / 226，两条分隔线在 74、185。

   * 实测：`sample_a1_.png` ↔ `sample_a2_.png` 距离 0；`batchA-141529` ↔ `batchA-141241` 距离 0、`sample_b1_` 距离 1；右键 `batchA-141529` 实际打开面板，标题「相似 2 张」、格子 2 个。全库指纹 528/528 补齐，重启后不重算。
2. **标记写成侧车文件**

**踩过的坑**：
